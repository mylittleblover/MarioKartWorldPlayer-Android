# JukeKart Beta 使用说明

**简体中文** | [繁體中文](USAGE.zh-Hant.md) | [English](USAGE.en.md) | [日本語](USAGE.ja.md)

## 安装和导入音乐

1. 在 Android 8.0 或更高版本上安装 JukeKart `Beta 0.1.6` Release APK。手机可能会要求授权安装来源。
2. 下载完整 [`.mkwpack` 资源包（MEGA）](https://mega.nz/file/j1BxBRyI#cJxJEof3uY3JxDSPiIep7WOI1mNyI2h3Vz7yZ3YRdOc)（或自备兼容的 `.mkwpack`），保存在系统文件选择器可访问的位置。应用会将曲包内容导入内部存储，请预留足够空间。曲包结构见[格式说明](PACK-FORMAT.zh-Hans.md)。
3. 首次启动可在欢迎页授权通知并直接选择导入 `.mkwpack`，也可随时打开 **设置 → 导入 .mkwpack** 选择文件并等待校验。完成后在导入详情查看可播放曲目。可以陆续导入多个曲包，内容会合并到曲库。
4. 导入中断后，可在设置里选择 **继续导入**。若系统文件访问授权过期，按提示重新选择同一个曲包。

如果手机上装过以旧测试证书签名的 Alpha，同包名的 Release APK 无法直接覆盖安装。请先导出应用内备份、另存原始曲包，再卸载旧版。卸载会清除应用内部文件。

## 播放和编辑

| 功能 | 操作 |
|---|---|
| 赛道控制台 | 从发现页选择有音频的赛道。控制台完整对齐 MKW v1.8.0 过渡规则，显示该赛道可用的阶段、收尾、最终圈加速、区域切换与双版本控制。 |
| 组曲与路线 | 在赛道或地图页面选择 121 首组曲、官方大奖赛/生存赛或自由行驶路线。可缩放、拖动地图，从赛道标记打开预览；纯自由行驶路线支持「按路线规则」与「游戏内自由行驶曲库」双模式。 |
| 自定义路线 | 在世界地图上沿 MKW v1.8.0 验证的 202 条有向连接边创建路线，支持顺序或随机道路规则与自由行驶曲库选项，完成后保存或播放。 |
| 自由行驶电台 | 在电台页按游戏内 13 张官方点唱机曲表畅听，支持自动昼夜、单人白天/夜晚、游戏内自由行驶全曲库、仅自由行驶独占曲及联网白天/夜晚共 7 种模式，内置 9 首历史去重与 1.5 秒切曲呼吸间隔。 |
| 流程编排器 | 在支持的赛道上打开流程编排器，编排阶段与切换模式，保存可复用的流程预设、导出/导入流程 JSON，或离线无损渲染导出 WAV / FLAC 音频。 |
| 曲目标记与制作人员名单 | 在播放器为任意曲目添加时间戳标记并一键跳转；播放《制作人员名单》（含 Nintendo Music 特别提供版自动偏移校准）时，进度条会随 18 个乐章动态滑入对应赛道主题色与彩虹之路流动渐变。 |
| 点唱机、主题与特别杯 | 支持全局搜索、收藏与播放列表管理；在 **设置** 中可通过角色主题抽屉切换 7 款马力欧角色主题、查看内置版本更新检查，并通过答题或听歌进度解锁特别杯与彩虹之路。 |
| 后台控制 | 开始播放后可离开应用，使用系统媒体控件、桌面小组件或快捷设置磁贴。Android 13 及以上可按应用提示授权通知。 |

赛道封面、地图和解锁视频可随曲包提供。缺少这些文件时，应用会显示内置的封面、地图或横屏动画。缺失的音频需要通过包含相应资源的曲包补齐。

## 备份与恢复

打开 **设置 → 数据备份与导出**，将备份保存到应用外。恢复时可选择**合并**或**替换**。替换会以备份中的播放列表、收藏、预设、路线、统计与设置覆盖当前数据。音频需通过原始 `.mkwpack` 重新导入。也可以单独导出 M3U 播放列表。

## 报告问题

反馈播放、导入或显示问题时，请写明 JukeKart 版本、设备型号、Android 版本、曲名或曲包版本及复现步骤。若问题出现在后台播放，也请注明当时使用的是通知、磁贴还是小组件。[提交 GitHub Issue](https://github.com/mylittleblover/JukeKart-Android/issues)
