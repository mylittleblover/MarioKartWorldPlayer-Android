# 使用说明

面向使用者。安装、加曲目、看懂界面。

---

## 1. 安装

```bash
adb install -r MKW-Player-0.1.0-alpha01.apk
```

或把 APK 传到手机上点击安装（需允许「安装未知来源应用」）。

**签名是测试身份**（`CN=MKW Player Debug`）。如果手机上装过别的签名的同名应用，
安装会因签名不匹配失败，需要先 `adb uninstall com.mylittleblover.mkwplayer`。

---

## 2. 加曲目

点 **Add a .bwav file** → 在系统文件选择器里选一个 `.bwav`。

应用会把文件**复制到自己的缓存**（按内容 SHA-256 命名），然后读出：

- 类别（COURSE / BATTLE / SEQUENCE …）
- 采样率（通常是 48000 Hz）
- 时长
- 能不能播

选过的曲目**重启后仍在**。移除时点曲目行的 **Remove**，会同时删掉缓存副本。

> 应用不内置任何游戏音频。`.bwav` 需要你自己提供（从游戏数据中提取）。

---

## 3. 界面怎么看

### 播放卡片

| 元素 | 含义 |
|---|---|
| 状态文字 | `No track loaded` / `Playing` / `Paused` / `Stopped` / `Failed` |
| 进度条 | **可拖动**，拖到哪跳到哪 |
| `0:12 / 1:10` | 当前位置 / 总时长 |
| Pause / Resume / Stop | 没在播时自动禁用 |

### Device timing 面板

这是音频回调的健康度，**直接反映会不会卡顿**：

| 显示 | 含义 | 该怎么办 |
|---|---|---|
| `HEALTHY` | 回调稳定在预算内 | 无 |
| `DEGRADED` | 丢帧超过 1%，或 CPU 占用超 70% 预算 | 可能偶尔有轻微爆音 |
| `FAILING` | 丢帧超过 5%，或 CPU 超 90% | 明显卡顿 |
| `NO DATA` | 还没有回调数据 | 正常 —— 未开始播放，或系统无音频输出 |

下面一行会写具体数字，例如：

```
54 callbacks, 1808 µs p99 CPU against 9500 µs budget (19%)
```

### Catalog 面板

650 条曲目按类别列出，每条标注 `playable` 或 `codec 2`。

卡片顶部写着这个目录的**覆盖范围**，请认真读：

```
Partial catalog: provisional incomplete, 4 of 499 archives read.
```

**这意味着目录不是完整原声带** —— 游戏里的曲目比列出来的多。只读了 499 个归档中的 4 个。

> 目录只说「存在什么」和「这个版本能解什么」。它**不代表**你手机上有这些文件。

---

## 4. 后台播放

开始播放后按 Home 键，音乐继续。

通知栏有 **Pause / Resume / Stop**，锁屏和耳机线控也能控制。

> 从 Android 13 起需要允许通知，否则媒体控件不会出现。应用会在首次播放时询问。

---

## 5. 已知问题

| 问题 | 原因 | 状态 |
|---|---|---|
| JukeBox / Cutscene 播不了 | 使用 BWAV codec 2，编码未解 | 预期行为，界面已标注 |
| 来电时音乐不暂停 | 音频焦点未实现 | **已知缺陷** |
| 拔耳机后外放继续 | 同上 | **已知缺陷** |
| 重启后要重新选文件才能播 | 音频字节不持久化，只存元数据 | 有意的取舍 |
| 目录条目比游戏里少 | 只读了 4/499 个归档 | 数据限制 |
| 模拟器上 `NO DATA` | 模拟器需不带 `-no-audio` 启动 | 环境问题 |

---

## 6. 报告问题

如果崩溃或播放异常，请提供：

```bash
adb logcat -d > logcat.txt
```

以及：

- 手机型号与 Android 版本
- 出问题的是哪个 `.bwav`（文件名即可）
- 界面上的 Device timing 显示什么

---

## 7. 什么是「已验证」的

这个项目的证据分两类，**不要混为一谈**：

| 类型 | 覆盖 | 可靠性 |
|---|---|---|
| 自动化测试（454 个） | 解码正确性、状态机、持久化、服务生命周期、容器解析 | 可重放 |
| 人耳听音（1 次） | 音高、爆音、loop 接缝、后台持续性 | 不可重放，依赖听者判断 |

**只有 `BGM_Stage_Coaster` 一首有人耳确认。** 其余曲目只经过数值验证（逐样本解码正确），
没有人听过。如果你发现某首听起来不对，那是新信息，请告诉我。
