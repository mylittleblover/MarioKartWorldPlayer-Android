## インストールと音楽のインポート

1. Android 8.0 以降の端末に JukeKart `Beta 0.1.6` Release APK をインストールします。必要に応じて提供元不明アプリのインストール許可を行ってください。
2. 完全版 [`.mkwpack` パック（MEGA）](https://mega.nz/file/j1BxBRyI#cJxJEof3uY3JxDSPiIep7WOI1mNyI2h3Vz7yZ3YRdOc)（または互換性のある自作 `.mkwpack`）をダウンロードし、システムファイルピッカーからアクセスできる場所に保存します。アプリはパック内容を内部ストレージへ取り込むため、十分な空き容量を確保してください。パック構造の詳細は[パック形式仕様](PACK-FORMAT.ja.md)を参照してください。
3. 初回起動時はウェルカム画面から通知権限の許可と `.mkwpack` のインポートをそのまま行えます。以降はいつでも **設定 → .mkwpack をインポート** からファイルを選択して検証を待つことで取り込めます。完了後は **インポートの詳細** で再生可能なトラックを確認できます。複数パックを順次インポートすると、ライブラリへ自動的に統合されます。
4. インポートが中断された場合は、設定画面の **インポートを再開** を選択してください。ファイルアクセス権限の有効期限が切れている場合は、案内に従って同一の `.mkwpack` ファイルを再選択してください。

旧テスト署名でビルドされた Alpha 版がすでに端末にインストールされている場合、同じパッケージ名の Release APK を直接上書きインストールすることはできません。先にアプリ内バックアップの書き出しと元の `.mkwpack` ファイルの保管を済ませてから旧版をアンインストールしてください（アンインストールするとアプリ内部データは削除されます）。

## 再生と編集

| 機能 | 操作方法 |
|---|---|
| コースコンソール | ホームから音源のあるコースを選択します。MKW v1.8.0 の実機切替ルールに準拠し、利用可能なパート、アウトロ、ファイナルラップ、エリア切替、楽曲バージョン切替が表示されます。 |
| メドレーとルート | コース画面またはマップ画面から 121 曲のメドレー、公式グランプリ／サバイバルルート、フリーランルートを選択できます。純粋フリーランルートでは「ルート規則」と「ゲーム内フリーラン曲庫」の 2 種類から選択可能です。 |
| カスタムルート | ワールドマップ上で MKW v1.8.0 検証済みの 202 本の有向接続ルートに沿って経路を作成し、道中 BGM 規則やフリーラン曲庫を選んで保存・再生できます。 |
| フリーランラジオ | ゲーム内公式 13 種の `SoundJukeBoxPlaylist` に準拠し、自動昼夜・ソロ昼／夜・ゲーム内フリーラン全曲庫・フリーラン限定曲・オンライン昼／夜の全 7 モードで再生できます（直近 9 曲の重複防止・曲間 1.5 秒の無音間隔対応）。 |
| フローエディター | 対応コースでフローエディターを開き、パートや切替方式を並べてプリセット保存、フロー JSON の書き出し／読み込み、さらに WAV / FLAC 形式でのオフライン書き出しを行えます。 |
| マーカーとスタッフロール | 任意の楽曲にタイムスタンプマーカーを保存して即座にシークできます。『スタッフロール』（Nintendo Music 特別配信版の自動オフセット補正対応）再生時は、18 セクションに合わせてプログレスバーが各コースのテーマカラーやレインボーロードのグラデーションへ滑らかに変化します。 |
| ジュークボックス・テーマ・スペシャルカップ | 全体検索やお気に入り・プレイリスト管理に加え、**設定** のテーマシートから 7 種のキャラクターテーマを切替でき、アプリ内アップデート確認やクイズ／視聴達成によるスペシャルカップ＆レインボーロード解放にも対応します。 |
| バックグラウンド操作 | 再生を開始したままアプリを離れても、システムのメディアコントロール、ホーム画面ウィジェット、クイック設定タイルで操作できます。Android 13 以降では案内に従って通知権限を許可してください。 |

コースカバー画像、マップ画像、解放演出動画はパックに同梱できます。これらが含まれない場合、アプリは内蔵のカバー・マップ・横画面アニメーションを表示します。不足している音源については、該当リソースを含むパックを追加インポートしてください。

## バックアップと復元

**設定 → バックアップとエクスポート** を開き、バックアップをアプリ外のストレージに保存します。復元時は **現在のデータと統合** または **すべて上書き復元** を選択できます。上書き復元では、プレイリスト、お気に入り、プリセット、ルート、再生統計、設定がバックアップ内容で置き換わります。音声ファイル自体は元の `.mkwpack` から再インポートする必要があります。プレイリスト単体の M3U 書き出しにも対応しています。

## 不具合の報告

再生・インポート・表示に関する不具合を報告する際は、JukeKart のバージョン、端末モデル、Android バージョン、曲名またはパックバージョン、再現手順を明記してください。バックグラウンド再生時の問題であれば、通知・クイック設定タイル・ウィジェットのどれを使用していたかもあわせてお知らせください。[GitHub Issue を作成](https://github.com/mylittleblover/JukeKart-Android/issues)
